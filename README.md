# 로아 패턴 오버레이

로스트아크 화면에 뜬 **보스 이름**과 **남은 줄 수(X 205)**를 읽어서, 미리 적어둔 패턴 메모를 게임 화면 위에 띄워주는 Windows 프로그램입니다.
보스가 없을 때(정비소)는 레이드·관문별 준비 메모(아군 위치, 배템 등)를 보여줍니다.

- 화면을 캡처해 Windows 내장 OCR로 글자만 읽습니다. 게임 메모리 읽기, 키 입력, 패킷 분석은 하지 않습니다.
- 평소에는 클릭이 게임으로 통과되고, 이동 모드(Ctrl+Shift+M)일 때만 드래그로 위치를 옮길 수 있습니다.
- 패턴은 레이드별 메모장 txt 파일로 관리하고, 다른 사람과 파일만 주고받아 공유할 수 있습니다.

## ⚠️ 사용 전에 반드시 읽어주세요

**이 프로그램은 게임사(스마일게이트)로부터 사용 허가를 받지 않았습니다. 사용하면 계정 제재를 받을 수 있습니다.**

제작자가 2026-10-21 로스트아크 고객센터에 이 프로그램의 사용·배포 가능 여부를 문의했고, 답변 요지는 다음과 같습니다.

- 홈페이지·스토브 클라이언트에서 제공하는 프로그램 외의 프로그램으로 게임을 이용하거나 게임에 영향을 주는 경우, 운영정책에 따라 조치될 수 있다.
- 이 프로그램이 게임에 어떤 영향을 주는지 명확하지 않아 **구체적인 안내(허용 여부 판단)는 어렵다.**
- 사용 이후 운영정책 위반이 확인되면 **계정에 불이익이 발생할 수 있다.**
- 다른 사용자에게 배포해도 되는지에 대해서는 별도 답변이 없었다.

즉, **허용도 금지도 확인받지 못한 상태**이며, 위반 여부는 게임사가 사후에 판단합니다.
[로스트아크 운영정책](https://clause.onstove.com/stove/terms?category=oppolicy&only_game=Y&game_id=45)의
불법 프로그램 정의에는 "기타 게임 서비스 이용에 간섭하거나 영향을 주는 비인가 외부 프로그램"이 포함되어 있고,
불법 프로그램 사용으로 판단되면 **1차부터 영구 이용 정지** 대상입니다.

- 사용 여부는 위 내용을 이해한 뒤 **본인이 판단**해 주세요. 제재 등 사용으로 인한 모든 결과의 책임은 사용자에게 있습니다.
- 로스트아크 **공식 홈페이지 게시판에는 이 프로그램을 공유하지 마세요.** 운영정책상 비공식 프로그램의 제작·공유·배포 관련 글은 삭제 및 글쓰기 제한 대상입니다.
- 게임사의 공식 입장이 바뀌거나 사용 중단을 요청받으면 이 저장소와 배포를 중단할 수 있습니다.

## 다운로드 / 사용법
[Releases](../../releases)에서 최신 `LoaPatternOverlay_v*.zip`을 받아 압축을 풀고 `LoaPatternOverlay.exe`를 실행하세요.
자세한 사용법은 압축 안의 `사용법.txt`를 참고하세요.

- 게임은 **창 모드 / 전체 창 모드**여야 합니다.
- 1920×1080 기준이며 다른 해상도는 자동 환산합니다. 안 맞으면 트레이 메뉴 → 인식 영역 설정.

## 패턴 파일 예시 (`patterns/레이드이름.txt`)
```
# 종막 : 최후의 날

== 1관문 ==
[정비소]
아드 암수
X3+1

[대악마, 카제로스]
420  첫 번째 패턴 설명
     들여쓰면 윗줄에 이어서 줄바꿈
350  두 번째 패턴 설명
```

## 직접 빌드하기 (제작자용)
Python 3.12 (Windows) 필요.
```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe build.py
```
결과물: `release\LoaPatternOverlay_v<버전>.zip`

소스로 바로 실행: `.venv\Scripts\python.exe src\main.py --debug`

## 구성
| 파일 | 내용 |
|---|---|
| `src/main.py` | 오버레이 창, 트레이, 단축키, 화면 캡처 루프 |
| `src/ocr.py` | Windows OCR 호출, 보스 이름/줄 수/관문 인식 |
| `src/patterns.py` | 패턴 txt 파일 읽기, 표시할 패턴 고르기 |
| `build.py` | PyInstaller로 exe 생성 + 배포 zip |
| `assets/` | 아이콘, 사용법, 예시 패턴, 라이선스 고지 |
