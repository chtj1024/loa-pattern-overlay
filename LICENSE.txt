이 소프트웨어(소스 코드, 실행 파일, 함께 배포되는 패턴 파일 포함)의 모든 권리는 제작자에게 있습니다.

[허용]
  1. 제작자가 공식 배포처(이 저장소의 Releases)에 올린 배포 파일을 내려받아
     수정하지 않은 상태로 개인적으로 사용하는 것
  2. 사용 중 patterns 폴더의 패턴 파일과 config.json을 본인 용도로 편집하는 것
  3. 소스 코드를 열람하는 것

[금지] (제작자의 사전 서면 허락 없이)
  1. 소스 코드 또는 실행 파일을 수정·변형하거나, 이를 바탕으로 2차 저작물을 만드는 것
  2. 원본 또는 수정본을 다른 곳에 다시 올리거나 배포하는 것 (공식 배포처 링크 공유는 허용)
  3. 판매, 유료 제공 등 영리 목적으로 사용하는 것

[책임의 한계]
  - 이 소프트웨어는 "있는 그대로" 제공되며, 어떠한 보증도 하지 않습니다.
  - 이 소프트웨어는 게임사로부터 사용 허가를 받지 않았습니다. 게임사 고객센터는

  - 공식 배포처 이외의 경로로 받았거나 제3자가 수정한 파일은 제작자가 만든 것이 아니며,
