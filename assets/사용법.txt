=====================================================
 로아 패턴 오버레이 - 사용법
=====================================================

화면에 뜬 보스 이름과 남은 줄 수(X 205)를 읽어서, 미리 적어둔 패턴 메모를
게임 화면 위에 띄워주는 프로그램입니다.
보스가 없을 때(정비소)는 레이드/관문별 준비 메모를 보여줍니다.

※ 화면을 캡처해 글자만 읽으며, 게임 메모리나 키 입력은 건드리지 않습니다.
※ 게임사가 공식 허용한 프로그램이 아닙니다. 사용 책임은 본인에게 있습니다.


■ 처음 실행
-----------------------------------------------------
1. 압축을 원하는 곳에 풉니다 (예: 바탕화면)
2. LoaPatternOverlay.exe 실행
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]
     (서명 인증서가 없는 개인 제작 프로그램이라 뜨는 경고입니다)
   - 처음 한 번 안내 문구에 [예]를 누르면 시작됩니다
3. 작업표시줄 오른쪽 트레이(^ 아이콘 안)에 노란 L 아이콘이 생기면 실행 중입니다
4. 게임은 반드시 [창 모드] 또는 [전체 창 모드]로 설정하세요.
   [전체 화면]에서는 오버레이가 보이지 않습니다.


■ 설정과 패턴은 어디에 저장되나요?
-----------------------------------------------------
  문서\로아 패턴 오버레이\
    ├─ 패턴\          ← 패턴 txt 파일 (여기서 편집)
    ├─ config.json    ← 위치·폰트·단축키 설정
    └─ log.txt        ← 오류 기록

- 처음 실행할 때 프로그램 폴더의 [처음 패턴]이 위 [패턴] 폴더로 한 번만 복사됩니다.
  그 뒤로는 [패턴] 폴더만 읽으며, 자유롭게 고치거나 지워도 됩니다.
- 트레이 메뉴 [패턴 폴더 열기] / [데이터 폴더 열기]로 바로 열 수 있습니다.


■ 새 버전으로 업데이트
-----------------------------------------------------
1. 새 버전 zip을 풀고 새 LoaPatternOverlay.exe 실행
2. 예전 버전 프로그램 폴더는 지워도 됩니다
   → 설정과 패턴은 문서 폴더에 그대로 남아 있어 따로 옮길 필요가 없습니다.
※ v1.0.0을 쓰던 경우: 새 버전을 예전 폴더와 같은 위치에 풀고 처음 실행하면
   예전 폴더의 설정과 패턴을 자동으로 옮겨 옵니다. (확인 후 예전 폴더 삭제)


■ 단축키
-----------------------------------------------------
  Ctrl+Shift+M : 이동 모드 켜기/끄기
                 켜져 있을 때만 드래그로 위치를 옮길 수 있고,
                 끄면 위치가 저장되고 다시 클릭이 게임으로 통과됩니다
  Ctrl+Shift+H : 오버레이 보이기/숨기기
  Ctrl+Shift+Q : 종료

트레이 아이콘을 우클릭하면 같은 기능과 [인식 영역 설정], [패턴 폴더 열기]가 있습니다.


■ 패턴 메모 쓰기  (문서\로아 패턴 오버레이\패턴 폴더의 txt 파일, 메모장으로 편집)
-----------------------------------------------------
레이드 하나에 파일 하나. 저장하면 실행 중에도 바로 반영됩니다.

  # 종막 : 최후의 날             ← 왼쪽 위에 뜨는 콘텐츠 제목 그대로

  == 1관문 ==                    ← 여기부터 1관문
  [정비소]                        ← 보스 피통이 없을 때 보여줄 메모
  아군 위치: 1파티 좌측
  배템: 회오리 수류탄

  [대악마, 카제로스]              ← 보스 피통 위에 뜨는 이름 그대로
  420  첫 번째 패턴 설명          ← 숫자 = 그 패턴이 나오는 남은 줄 수
       들여쓰면 윗줄에 이어서 줄바꿈
  350  두 번째 패턴 설명

  == 2관문 ==
  ...

- 들여쓰기: 줄 맨 앞에 스페이스(1칸 이상)나 Tab
- // 로 시작하는 줄은 메모(무시)
- '# 제목'이 없는 파일의 보스는 어느 레이드에서든 사용됩니다
- 파일 이름이 _ 로 시작하면 읽지 않습니다 (_작성법.txt)
- 형식이 틀린 줄이 있으면 트레이 알림으로 "파일명 몇 번째 줄"을 알려줍니다
- 다른 사람이 만든 레이드 txt 파일을 [패턴] 폴더에 넣기만 하면 바로 사용됩니다


■ 화면 표시
-----------------------------------------------------
- 보스 피통이 있으면: 지금 진행 중인 패턴(노란색 ▶) + 이전 2개 + 다음 2개
  (진행 중 = 현재 줄 수보다 큰 패턴 중 가장 작은 것)
- 보스 피통이 없으면: 현재 레이드/관문의 [정비소] 메모
- 관문은 왼쪽 위 관문 아이콘의 초록 체크(V) 개수로 판단합니다.
  관문 표시는 펼친 상태(∧)로 두세요.


■ 인식이 안 될 때
-----------------------------------------------------
- 1920x1080 기준으로 만들었고, 다른 해상도는 위치를 자동으로 환산합니다.
  그래도 안 맞으면 트레이 메뉴 → [인식 영역 설정]에서
  ① 보스 이름 ② X 205 ③ 왼쪽 위 콘텐츠 제목 ④ 관문 아이콘 줄
  을 차례로 드래그하세요 (중간에 Esc = 거기까지만 저장).
- "한국어 OCR이 없습니다" 오류: Windows 설정 → 시간 및 언어 → 언어 및 지역
  → 한국어 → 언어 옵션 → [광학 문자 인식] 설치
- 문제가 계속되면 문서\로아 패턴 오버레이\log.txt를 제작자에게 보내주세요.
  (자세한 기록이 필요하면 명령 프롬프트에서  LoaPatternOverlay.exe --debug  로 실행)


■ 설정 (문서\로아 패턴 오버레이\config.json, 메모장으로 편집 후 프로그램 재시작)
-----------------------------------------------------
  overlay.font_size       글씨 크기
  overlay.color_next      진행 중 패턴 색 (기본 노란색 #ffd54a)
  overlay.color_prev      이전 패턴 색
  overlay.color_after     다음 패턴 색
  overlay.color_prep      정비소 메모 색
  overlay.max_width       오버레이 최대 너비(px), 넘으면 자동 줄바꿈
  overlay.background_alpha  글씨 뒤 검은 배경 진하기 0~255 (0 = 없음)
  hotkeys                 단축키 (예: "ctrl+shift+m", "alt+f1")

설정이 꼬였으면 config.json을 지우고 다시 실행하면 기본값으로 돌아갑니다.
